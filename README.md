# 🌐Tradutor de Texto

Uma ferramenta simples para traduzir textos entre diferentes idiomas.

## Funcionalidades

- Campo para inserir o texto
- Seleção do idioma de origem
- Seleção do idioma de destino
- Tradução do texto
- Exibição do resultado

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
